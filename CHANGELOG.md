# v1.0.17 (unreleased)

### Added

Backup Manager for root app backup and restore.

### Improved

Backup Manager is available directly from the top bar.
Backups are grouped into dated backup jobs.
Backup jobs can be opened inside Backup Manager to view and restore individual apps.
Backup and restore now show clear progress while running.

### Fixed

Backup and restore failures now show an error instead of closing the app.
App data restore now runs root file operations correctly.
Pulling files to a protected Windows folder now stops with a clear destination error instead of reconnecting repeatedly.
